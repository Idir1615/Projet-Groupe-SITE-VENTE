# 🛒 JulienSelling : site de vente en ligne

Site e-commerce **statique** réalisé en groupe dans le cadre du BTS SIO.

## 📌 Pages

| Page | Description |
|---|---|
| `index.html` | Accueil avec carrousel |
| `product.html` | Catalogue de produits |
| `about.html` | À propos |
| `testimonial.html` | Témoignages clients |
| `contact.html` | Contact |

## 🛠️ Technologies

HTML5 · CSS3 / SCSS · JavaScript · jQuery 3.4 · Bootstrap 4 · Font Awesome

## 🚀 Lancer le projet

Ouvrir `index.html` dans un navigateur.

Pour modifier les styles, éditer `css/style.scss` puis le recompiler en `css/style.css` (avec l'extension *Live Sass Compiler* de VS Code ou avec `sass css/style.scss css/style.css`).

## 📁 Structure

```
├── *.html     # Pages du site
├── css/       # Bootstrap, styles personnalisés (SCSS), responsive
├── js/        # jQuery, Bootstrap, scripts personnalisés
├── images/    # Visuels
└── fonts/     # Polices d'icônes
```

> La version dynamique avec base de données se trouve dans le dépôt [SITE-IMMO-BDD](https://github.com/Idir1615/SITE-IMMO-BDD).
